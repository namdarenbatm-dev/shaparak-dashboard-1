# 📊 داشبورد KPI کارتخوان شاپرک

داشبورد هوشمند استخراج و تحلیل شاخص‌های کلیدی عملکرد شبکه کارتخوان (POS) از گزارش‌های ماهانه شاپرک.

## 🎯 ویژگی‌ها

- **استخراج خودکار از PDF شاپرک**: آپلود گزارش ماهانه و استخراج ۵ شاخص کلیدی:
  - تعداد کل تراکنش‌های کارت‌خوان
  - مبلغ کل تراکنش‌های کارت‌خوان (ریال)
  - تعداد کل کارت‌خوان‌های شبکه
  - تعداد کارت‌خوان فعال سیستمی
  - تعداد کارت‌خوان غیرفعال سیستمی

- **تحلیل داده‌های PSP**: آپلود فایل اکسل/CSV حاوی داده‌های شرکت‌های PSP و مشاهده:
  - کل کارتخوان‌های نصب‌شده، فعال و راکد
  - جدول رتبه‌بندی PSPها بر اساس بهره‌وری تراکنشی (TP)
  - بهره‌وری مبلغی و میانگین ارزش تراکنش (ATV)

- **بدون نیاز به نصب**: فقط فایل HTML را در مرورگر باز کنید.

## 🚀 نحوه استفاده

### روش 1: اجرای محلی

1. فایل `index.html` را دانلود کنید.
2. روی آن دوبار کلیک کنید تا در مرورگر باز شود.
3. فایل PDF گزارش شاپرک یا اکسل داده‌های PSP را آپلود کنید.

### روش 2: استفاده از GitHub Pages

اگر این ریپازیتوری را Fork یا Clone کرده‌اید:

1. در GitHub، به **Settings → Pages** بروید.
2. Branch را روی `main` و پوشه را روی `/(root)` تنظیم کنید.
3. بعد از چند دقیقه، داشبورد در لینک زیر قابل دسترسی است:
   ```
   https://your-username.github.io/shaparak-dashboard/
   ```

## 📁 ساختار فایل‌های ورودی

### فایل اکسل/CSV داده‌های PSP

فایل ورودی باید شامل ستون‌های زیر باشد:

| نام ستون | توضیح |
|---------|-------|
| `psp_name` | نام شرکت PSP |
| `installed_pos` | تعداد کارتخوان نصب‌شده |
| `active_pos` | تعداد کارتخوان فعال |
| `total_tx_count` | تعداد کل تراکنش‌ها |
| `total_tx_amount` | مبلغ کل تراکنش‌ها (ریال) |

**نمونه فایل CSV:**

```csv
psp_name,installed_pos,active_pos,total_tx_count,total_tx_amount
PSP A,10000,8500,1200000,125000000000
PSP B,8000,7000,950000,99000000000
PSP C,12000,9500,1500000,180000000000
```

### فایل PDF گزارش شاپرک

- گزارش ماهانه رسمی شاپرک (فرمت PDF)
- شامل آمار تفکیکی کارتخوان فروشگاهی (PC-POS)

## 🧮 فرمول‌های محاسباتی

- **کارتخوان راکد**: `installed_pos - active_pos`
- **بهره‌وری تراکنشی (TP)**: `total_tx_count / installed_pos`
- **بهره‌وری مبلغی**: `total_tx_amount / installed_pos`
- **میانگین ارزش تراکنش (ATV)**: `total_tx_amount / total_tx_count`

## 🛠 فناوری‌های استفاده‌شده

- **HTML5 + CSS3**: ساختار و استایل داشبورد
- **JavaScript (Vanilla)**: منطق پردازش و استخراج داده
- **PDF.js**: پردازش و استخراج متن از PDF شاپرک
- **SheetJS (XLSX)**: خواندن فایل‌های اکسل و CSV

## 📌 نکات مهم

- برای اجرای داشبورد نیاز به اینترنت دارید (بارگذاری کتابخانه‌های PDF.js و SheetJS از CDN).
- استخراج از PDF شاپرک بر اساس کلیدواژه‌های فارسی انجام می‌شود؛ در صورت تغییر ساختار گزارش، ممکن است نیاز به تنظیم کلیدواژه‌ها باشد.
- در صورت مشاهده هشدار «تعداد کل دستگاه‌ها با جمع فعال و غیرفعال هم‌خوان نیست»، داده‌های استخراج‌شده را بررسی کنید.
